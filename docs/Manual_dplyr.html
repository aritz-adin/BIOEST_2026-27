El paquete dplyr

dplyr es uno de los paquetes más utilizados del lenguaje de programación R para manipular y analizar datos. Sus funciones permiten seleccionar variables de una base de datos, filtrar observaciones, crear nuevas variables, agrupar los datos y calcular estadísticos descriptivos de forma sencilla y comprensible.

Para utilizar dplyr, primero hay que cargar el paquete:

library(dplyr)

Una vez cargado el paquete, todas sus funciones estarán disponibles durante toda la sesión.

En esta asignatura se utilizarán principalmente las siguientes funciones del paquete dplyr:

  • select(): para seleccionar variables

  • filter(): para filtrar observaciones

  • mutate(): para crear nuevas variables

  • group_by(): para agrupar las observaciones según una variable

  • summarise(): para calcular estadísticos descriptivos para cada grupo

Además, en algunos ejemplos se utilizarán las siguientes funciones:

  • case_when(): para recodificar variables

  • factor(): para definir las categorías de una variable cualitativa y su orden

  • pull(): para obtener los valores de una variable como vector

  • shapiro.test(): para realizar el test de normalidad de Shapiro-Wilk

  • eda(): para realizar un análisis exploratorio de datos (exploratory data analysis; función del paquete PASWR2)

El operador pipe (|>)

El operador pipe (|>) permite encadenar varias operaciones de forma consecutiva.

Este operador pasa automáticamente el resultado de la expresión anterior a la siguiente función.

Datos |> 
  Operacion1() |> 
  Operacion2() |> 
  Operacion3()

Por tanto, gracias al operador |>, no es necesario volver a escribir el nombre de la base de datos en cada función. Esto hace que el código sea más corto, claro y fácil de leer.

Seleccionando variables: select()

La función select() se utiliza para seleccionar variables (columnas) de una base de datos.

Por ejemplo, para seleccionar únicamente las variables kgy cm del fichero EPIDURAL

Filtrando observaciones: filter()

La función filter() se utiliza para seleccionar las observaciones (filas) de una base de datos, manteniendo únicamente aquellas que cumplen una o varias condiciones.

Por ejemplo, para filtar las pacientes atendidas por el Dr. A con peso superior a 90kg:

EPIDURAL |> 
  filter(doctor=="Dr. A", kg>90)
# A tibble: 6 × 7

Creando nuevas variables: mutate()

La función mutate() se utiliza para crear nuevas variables en una base de datos o modificar variables existentes.

Por ejemplo, para crear en la base de datos EPIDURAL la nueva variable \(IMC=kg/(cm/100)^2\):

EPIDURAL |> 
  mutate(IMC=kg/(cm/100)^2) |> 
  select(kg, cm, IMC)
